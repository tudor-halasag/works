# Works — Tudor-Andrei Hălășag

Portfolio of engineering and robotics projects.  
Live: [tudor-halasag.github.io/works](https://tudor-halasag.github.io/works/)

## Stack

React · Vite · GitHub Pages · Google model-viewer

## Structure

```
src/
  App.jsx     # components & data
  App.css     # styles
public/       # .glb models & assets
```

## Local dev

```bash
npm install
npm run dev
```

## Build & deploy

```bash
npm run build   # outputs to dist/
```

CI deploys automatically via `.github/workflows/deploy.yml` on push to `main`.
